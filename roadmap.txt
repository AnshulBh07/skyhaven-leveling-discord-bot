🎯 CORE FEATURES: DISCORD LEVELING SYSTEM

1. 📈 XP & LEVELING SYSTEM
   - Users gain XP based on message activity (with cooldown to prevent spam farming).
   - XP-to-level formula (e.g. `XP = 5 * level² + 50 * level + 100`) determines level-ups.
   - Level-up detection and notification in a dedicated channel.

3. 🧍 USER COMMANDS
   - `/rank` – Display user level, XP, and rank.
   - `/leaderboard` – Show top users in the server by level.

4. 🗃️ DATABASE INTEGRATION
   - Store user data (XP, levels) and guild settings in MongoDB for persistence.

5. 🚫 RESTRICTIONS
   - No XP from:
     - Bots
     - Slash commands
     - Ignored or blacklisted channels
     - Non-text channels (e.g. voice)
   - Commands cannot be used in blacklisted channels.
   - Anti-spam cooldown applied per user per guild.

***** PHASE 2 *****
👤 ECONOMY AND ADMIN COMMANDS

1. 🛠️ ADMIN COMMANDS
All of the following are subcommands under: /xpconfig

   - `/xpconfig notif-channel`         → Set the notification channel for level-up messages.
   - `/xpconfig ignore-channel`        → Prevent XP gain in specified channels.
   - `/xpconfig listen-channel`        → Remove a channel from the ignore list.
   - `/xpconfig blacklist-channel`     → Block all command usage in a channel.
   - `/xpconfig whitelist-channel`     → Remove a channel from the blacklist.
   - `/xpconfig view`                  → View the current server configuration for the bot.


2. 💰 ECONOMY COMMANDS
   - `/setxp @user <amount>`           → Set a user's XP to a specific amount.
   - `/addxp @user <amount>`           → Add XP to a user.
   - `/removexp @user <amount>`        → Removes specified amount of xp from user.
   - `/setlevel @user <level>`         → Set a user's level manually.
   - `/resetserverxp`                  → Reset XP and levels for **all users** in the server.

- /gq leaderboard

- /gq channel
  • Sets the channel where Guild Quest submissions are logged or reviewed.

- /gq role <role>
  • Assigns a role that determines access to Guild Quest participation or admin commands.

- /gq add-admin <user>
  • Grants Guild Quest admin permissions to the specified user.

- /gq remove-admin <user>
  • Revokes Guild Quest admin permissions from the specified user.

📖 Seraphina's Fuzzy PDF Skill Guide System
------------------------------------------------------------------------------------------------------------
Seraphina, Skyhaven’s divine Discord bot, can now intelligently answer gameplay-related questions using uploaded skill or strategy documents. This system combines fuzzy search, document analysis, and LLM response generation to allow users to query Seraphina about builds, combos, DPS, or stats — and receive lore-rich, mood-based answers in return.

✨ Overview
This system allows Seraphina to:

- Store a set of PDF documents (skill guides, stat sheets, combo references)
- Fuzzily match user questions to the most relevant document
- Read and interpret the PDF using Gemini’s multimodal capabilities
- Respond to the user in-character, matching her divine mood and style

This enables true gameplay support without requiring the user to upload a file every time.

🧭 Flow of Operation
1. 🔍 Fuzzy Matching
When a user asks a gameplay-related question, such as:

“What’s a good halberd burst combo?”

The bot uses fuzzy string matching (via Fuse.js) to compare the user’s query against the document names and keywords. The closest-matching document is selected as the most likely source of relevant information.

2. 📤 Document Injection
Once the correct PDF is selected, it is:

Loaded from disk

Converted to base64

Passed to Google’s Gemini model as inline document content

3. 🧠 LLM Prompt Composition
A custom prompt is constructed based on:

The user's question

The selected document

Seraphina's current mood (e.g., tsundere, cheerful, cold)

Example prompt:

“The user asks: ‘What’s a good halberd burst combo?’
Use the attached document to answer in the tone of a divine tsundere. Be informative, sarcastic if needed, and avoid robotic responses.”

This prompt ensures Seraphina stays in-character while also leveraging accurate data from the PDF.

4. 💬 Response Delivery
Gemini generates a detailed, mood-rich response based on the document contents. This reply is then sent to the Discord channel as Seraphina’s divine guidance.

Example response:

“Tch. You want to burst like a pro? Use Dragon Tooth at the end, obviously. Don’t forget Impact first unless you enjoy wasting MP like a clueless scrub.”

✅ Benefits of This System
Feature	Description
📄 Reusable Documents	Admins can upload meta guides once — users can query them forever
🔍 Flexible Matching	Fuzzy search means users don’t need perfect wording
🧙 Personalized Replies	Seraphina answers in her unique tone and mood
🧠 Grounded & Informed	Answers are based on real game guides, not hallucinated lore
🔁 Scalable	Add more PDFs and keywords over time to improve coverage

🔒 Limitations
Gemini's PDF size cap is ~10MB

Does not support image-based (scanned) PDFs — must be text-based

Only one document is used per query (no multi-file fusion yet)

Fuzzy match quality depends on metadata coverage

Auto-summarize each document into long-term memory

Let users browse or request document list via /guide list
